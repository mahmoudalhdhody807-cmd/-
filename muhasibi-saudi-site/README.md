# مُحاسِبي — أكاديمية المحاسبة السعودية

تطبيق تعليمي عربي تفاعلي (RTL) صُمم ليعمل مباشرة من ملفات ثابتة، ويمكن نشره على GitHub Pages. يجمع بين منهج نظري واختبارات تدريجية ومكتب حالات عملية ومختبر ERP محلي للتدرب على القيود ودفتر الأستاذ وميزان المراجعة والقوائم المالية.

## تشغيله محليا

1. فك ضغط `muhasibi-saudi.zip` إن كنت تستخدم الملف المضغوط.
2. افتح `index.html` في متصفح حديث. إذا لم يسمح المتصفح ببعض وظائف التخزين عند الفتح المباشر، شغل خادم ملفات محليا (مثلا إضافة Live Server في VS Code).
3. تقدم المنهج وبيانات مختبر ERP تحفظ في `localStorage` داخل المتصفح الحالي. لا تنتقل تلقائيا بين الأجهزة أو المتصفحات.

## نشر الموقع على GitHub Pages

1. أنشئ مستودعا جديدا على GitHub.
2. ارفع محتويات هذا المجلد نفسها إلى جذر المستودع: `index.html` و`styles.css` و`app.js` و`content.js` ومجلد `assets` وملف `README.md`.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**، وحدد فرع `main` والمجلد `/ (root)`، ثم اضغط **Save**.
5. انتظر اكتمال النشر، ثم افتح الرابط الذي تعرضه صفحة Pages.

لا يحتاج الموقع إلى Node.js أو قاعدة بيانات أو مفاتيح API أو خدمة استضافة مدفوعة. قد يتطلب ظهور التحديثات بعد تعديل الملفات إعادة تحميل قوية للصفحة أو الانتظار قليلا حتى يحدث GitHub Pages نسخة النشر.

## ما الذي يتضمنه؟

- واجهة عربية كاملة واتجاه RTL، مع وضع ليلي افتراضي وإمكانية التبديل إلى الوضع الفاتح.
- رسومات SVG أصلية محفوظة محليا داخل `assets`، دون اعتماد على مكتبات أو صور خارجية.
- 23 فصلا تعليميا متدرجا: أساس المحاسبة، الدورة المحاسبية، الذمم والبنوك والمخزون والأصول والإقفال والقوائم المالية، الإطار السعودي، ضريبة القيمة المضافة، فاتورة، الزكاة وضريبة الدخل والاستقطاع، الرواتب والتأمينات، ERP/Odoo، اختلاف القطاعات، المقابلات، المعايير المتقدمة، التكاليف والموازنات، المعاملات الخاصة والمراجعة.
- اختبار لكل فصل بمؤقت؛ يمكن الانتقال للفصل التالي بعد اجتياز اختبار الفصل الحالي بنسبة 65% على الأقل. يمكن إعادة المحاولة، وتُحفظ النتيجة محليا.
- مكتب حل مشكلات يضم سيناريوهات أخطاء مع إجابات وتفسير وخطوات معالجة.
- سيناريوهات يوم المحاسب في المطاعم والمقاولات والتجارة والخدمات والفنادق والمصانع.
- محاكاة مقابلات تسمح بكتابة الإجابة ومقارنتها بعناصر الإجابة المقترحة.
- مختبر ERP: دليل حسابات، مستندات تدريبية، إضافة فواتير بيع وشراء وأصول ومصروفات، قيود يومية وتسويات متوازنة، أستاذ عام، ميزان مراجعة قبل التسويات وبعدها، قوائم مالية، قائمة تدفقات نقدية تدريبية، وإقفال حسابات الإيرادات والمصروفات.
- تنزيل واستيراد نسخة احتياطية JSON وتصدير اليومية وميزان المراجعة إلى CSV.
- مكتبة روابط للمصادر الرسمية السعودية.

## بدء مختبر ERP

1. افتح **مختبر ERP** ثم اختر **إنشاء شركة التدريب وفتح النظام**.
2. افتح **المستندات والفواتير** وسجّل المستندات المتاحة. تحصيل العميل وسداد المورد مرتبطان بتسجيل الفواتير ذات الصلة أولا.
3. افتح **قيود اليومية** لتسجيل قيد يدوي أو قيد تسوية، مثل مصروف الإهلاك: مدين «مصروف الإهلاك» ودائن «مجمع الإهلاك».
4. قارن **ميزان المراجعة قبل التسويات وبعدها**، ثم افتح **دفتر الأستاذ** وحدد الحساب لفحص الحركة.
5. افتح **القوائم المالية** لمشاهدة أثر القيود؛ ثم جرّب قيد الإقفال بعد مراجعة الأرصدة.
6. يمكنك تصدير بيانات التدريب أو تنزيل نسخة احتياطية قبل إعادة ضبط المختبر.

## حدود مهمة

- هذا تطبيق تعليمي محلي، وليس نظام محاسبة تجاري معتمدا أو بديلا عن Odoo أو عن نظام ERP مستخدم فعليا في منشأة.
- جميع بيانات الشركة والفواتير والأرقام في مختبر ERP افتراضية. لا تدخل بيانات رواتب أو هويات أو حسابات مصرفية لأشخاص حقيقيين.
- نظام المختبر لا يتصل ببوابة فاتورة أو زاتكا أو التأمينات الاجتماعية، ولا يقدم أو يرسل إقرارا حكوميا.
- نسبة 15% مستخدمة في أمثلة ضريبة القيمة المضافة على المعاملات المفترضة الخاضعة للنسبة الأساسية فقط. لا يعني ذلك أن كل سلعة أو خدمة تخضع للنسبة نفسها أو أن ضريبة المدخلات قابلة للخصم في كل حالة.
- أحكام الزكاة وضريبة الدخل والاستقطاع والتأمينات والفوترة الإلكترونية تتوقف على الوقائع والصفة القانونية والفترة والنصوص السارية. بعض المعدلات والمواعيد لا تدرج في المختبر كقيم ثابتة تجنبا لتعميم غير صحيح.
- المحاكاة المالية تغطي القواعد التعليمية الأساسية، لكن قائمة التدفقات النقدية المبسطة والتقارير ليست قائمة نظامية مدققة. عند استخدام بيانات فعلية، راجع المعايير والأنظمة واللوائح والأدلة الرسمية السارية واستعن بمختص في الحالات المعقدة.
- نجاح اختبار داخل الموقع لا يمثل اعتمادا مهنيا أو ضمان توظيف؛ الغرض منه بناء المعرفة والتدرب على التفكير المنهجي.

## المصادر الرسمية الأساسية

توجد روابط مباشرة داخل التطبيق إلى هيئة الزكاة والضريبة والجمارك (ZATCA)، والهيئة السعودية للمراجعين والمحاسبين (SOCPA)، والمؤسسة العامة للتأمينات الاجتماعية، ووزارة الموارد البشرية والتنمية الاجتماعية، ووثائق Odoo الخاصة بالتوطين السعودي. تاريخ مراجعة الروابط: أكتوبر 2026. قد تتغير الروابط أو اللوائح؛ تحقق من النسخة الحالية عند التطبيق المهني.

## ملفات المشروع

- `index.html`: هيكل الواجهة.
- `styles.css`: التصميم الداكن والمتجاوب والوضع الفاتح.
- `app.js`: التفاعلات والمنهج وحفظ التقدم ومحاكاة ERP والتقارير.
- `content.js`: الفصول والأسئلة والمستندات والروابط الرسمية.
- `assets/`: العلامة والرسومات التوضيحية المحلية.
